# Calculadora no terminal

Calculadora de linha de comando: mostra um menu com as quatro operações, lê os dois valores, exibe o resultado e pergunta se você quer continuar.

Projeto de estudo de 2023 (Python), mantido aqui como registro da minha evolução.

## Como rodar

```bash
python calculadoraComp.py
```

## O que pratiquei

- Laços `while` com condição de parada
- Entrada e conversão de dados (`input`, `float`)
- Estruturas condicionais encadeadas
